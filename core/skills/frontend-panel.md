Convenciones del frontend del proyecto:
- HTML, CSS y JavaScript puro, sin frameworks ni CDN.
- El estilo es un panel oscuro: fondo #0b0f17, paneles #121826, borde #253049, acento verde #4ade80 y cian #38bdf8, texto #e6edf7.
- La interfaz habla con la API con fetch() a rutas relativas de /api y maneja la respuesta con .then().
- Mantené el lenguaje visual existente (tarjetas .tarjeta, .stat, fuente Segoe UI) al agregar secciones.
- Los textos de la interfaz van en español.
